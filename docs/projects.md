# プロジェクト / Projects

研究室で実施中・実施済みの外部資金プロジェクト（科研費・共同研究）を紹介します．

<p lang="en">This page introduces the funded projects (JSPS KAKENHI grants and joint research projects) conducted in our laboratory.</p>

## 科研費 / JSPS KAKENHI

### データ記録時刻を基盤とした異種データの関連付けによる情報アクセス技術の構築

**Information access technologies based on associating heterogeneous data by recording time**

<span class="ptag ptag-mm">マルチモーダル / Multimodal</span> <span class="ptag ptag-ir">情報検索 / Information Retrieval</span> <span class="ptag ptag-ll">ライフログ / Lifelog</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2025年4月 – 2028年3月（進行中 / Ongoing）
    - **種別 / Program**：基盤研究（C）・研究代表者 / Grant-in-Aid for Scientific Research (C), PI
    - **リンク / Link**：[KAKEN](https://kaken.nii.ac.jp/ja/grant/KAKENHI-PROJECT-25K15243/){:target="_blank"}

本研究は，センサ，画像，位置情報等の異なるモダリティを対象に，データ記録時刻を手がかりとしてデータ間の関連を推定する情報アクセス手法を検討します．大規模なマルチモーダルデータの構築・検索に，この方法がどの程度寄与できるかを評価します．

<p lang="en">This project studies information-access methods that use recording time as a clue for estimating relationships among sensor, image, location, and other modalities. We evaluate how these methods can contribute to building and retrieving large-scale multimodal data.</p>

### ユーザの時間選好を考慮した健康行動変容のためのメッセージ提示戦略モデルの構築

**A message delivery strategy model for health behavior change considering users' time preference**

<span class="ptag ptag-be">行動経済学 / Behavioral Economics</span> <span class="ptag ptag-bc">行動変容 / Behavior Change</span> <span class="ptag ptag-hc">ヘルスケア / Healthcare</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2024年8月 – 2026年3月（終了 / Completed）
    - **種別 / Program**：研究活動スタート支援・研究代表者 / Grant-in-Aid for Research Activity Start-up, PI
    - **リンク / Link**：[KAKEN](https://kaken.nii.ac.jp/ja/grant/KAKENHI-PROJECT-24K23877/){:target="_blank"}

健康に関する選択には，目先の利益を将来の利益より重視する時間選好が関係する場合があります．本課題では，時間選好の個人差を考慮したメッセージ提示を設計し，どのような条件で健康行動の支援に有効かを評価します．

<p lang="en">Time preference—the tendency to value immediate outcomes more strongly than future outcomes—may be related to health choices. This project designs message strategies that consider individual differences in time preference and evaluates the conditions under which they may support health-related behavior.</p>

### 行動科学の知見とデータサイエンスの融合：目標達成過程を題材として

**Integrating behavioral science and data science: goal pursuit as a subject**

<span class="ptag ptag-be">行動経済学 / Behavioral Economics</span> <span class="ptag ptag-bc">行動変容 / Behavior Change</span> <span class="ptag ptag-uba">ユーザ行動分析 / User Behavior Analysis</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2024年4月 – 2028年3月（進行中 / Ongoing）
    - **種別 / Program**：基盤研究（B）・研究分担者（研究代表者：戸田 浩之 教授・横浜市立大学） / Grant-in-Aid for Scientific Research (B), Co-Investigator (PI: Prof. Hiroyuki Toda, Yokohama City University)
    - **リンク / Links**：[KAKEN](https://kaken.nii.ac.jp/ja/grant/KAKENHI-PROJECT-24K03046/){:target="_blank"} ／ [戸田研究室 / Toda Lab](https://sites.google.com/view/toda-lab/){:target="_blank"}

目標の達成過程では，目先の利益，習慣，周囲の状況等，複数の要因が行動に関係します．本課題では，実際の行動データと行動科学の知見を組み合わせ，人の目標達成過程を記述する数理モデルと，行動を支援する介入方法の構築・評価に取り組みます．

<p lang="en">Goal-pursuit behavior may be related to multiple factors, including immediate rewards, habits, and surrounding circumstances. This project combines behavioral data with insights from behavioral science to build and evaluate mathematical models of goal-pursuit processes and methods for supporting behavior.</p>

## 共同研究 / Joint Research

### マルチモーダル情報検索（株式会社デンソーアイティーラボラトリ）

**Multimodal information retrieval (DENSO IT Laboratory, Inc.)**

<span class="ptag ptag-mm">マルチモーダル / Multimodal</span> <span class="ptag ptag-ir">情報検索 / Information Retrieval</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2025年7月 – 2027年3月（進行中 / Ongoing）
    - **種別 / Program**：共同研究 / Joint research

画像・センサなど複数のモダリティを横断するマルチモーダル情報検索技術の研究開発に取り組んでいます．関連する成果として，マルチモーダルデータに基づく運転手の関心物体推定や，ライフログを用いた心拍数予測に基づく異常検知（いずれもDEIM2026発表）があります．

<p lang="en">We are developing multimodal information retrieval technologies across modalities such as images and sensor data. Related outcomes include estimating objects of driver interest based on multimodal data and anomaly detection based on heart-rate prediction using lifelogs (both presented at DEIM2026).</p>

### 行動経済学的な意思決定特性が魚食行動に与える影響の検討（Umios株式会社）

**Effects of behavioral-economic decision-making characteristics on fish-eating behavior (Umios Corporation)**

<span class="ptag ptag-be">行動経済学 / Behavioral Economics</span> <span class="ptag ptag-hc">ヘルスケア / Healthcare</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2025年10月 – 2027年3月（進行中 / Ongoing）
    - **種別 / Program**：共同研究 / Joint research

消費者の魚介類喫食行動を対象に，行動経済学的な意思決定特性と食行動との関係をデータ分析により検討しています．関連する成果として，消費者の魚介類喫食行動における理想と現実の乖離に関する分析（電子情報通信学会LOIS研究会にて発表）があります．

<p lang="en">We analyze associations between behavioral-economic decision-making characteristics and consumers' fish-eating behavior. A related outcome is an analysis of the gap between ideals and reality in consumers' seafood-eating behavior (presented at the IEICE LOIS workshop).</p>

### クロスモーダルな情報アクセス技術の研究開発を加速する大規模研究資源の構築（国立情報学研究所）

**Building large-scale research resources to accelerate R&D of cross-modal information access technologies (National Institute of Informatics)**

<span class="ptag ptag-mm">マルチモーダル / Multimodal</span> <span class="ptag ptag-ir">情報検索 / Information Retrieval</span> <span class="ptag ptag-eval">評価基盤 / Evaluation Resources</span>

!!! abstract "プロジェクト情報 / Project Info"
    - **期間 / Period**：2024年7月 – 2025年3月（終了 / Completed）
    - **種別 / Program**：NII公募型共同研究 / NII open call joint research

クロスモーダル情報アクセス研究を加速するための大規模研究資源（データセット・評価基盤）の構築に取り組みました．時間的近接性を用いたセンサ・画像のクロスモーダル検索（MMM2025）などの成果につながっています．

<p lang="en">We built large-scale research resources (datasets and evaluation infrastructure) to accelerate cross-modal information access research, leading to outcomes such as cross-modal retrieval of sensor and image data with temporal closeness (MMM2025).</p>
